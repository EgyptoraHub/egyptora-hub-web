# Prompt 46 — Trade, Industry & Agriculture public pages: verification

Date: 2026-11-07. All checks run signed out on the preview (maintenance mode ON; preview host bypasses the public closure as designed). Nothing was published.

## What was built

- Seven routes under Do Business:
  - `/do-business/industry-agriculture` (sector list, group filter via `?group=`)
  - `/do-business/industry-agriculture/$slug` (sector detail)
  - `/do-business/world-gateway` (country profiles, `?q=` + `?region=`)
  - `/do-business/world-gateway/$slug` (country detail with raw-material vs manufactured/services commodity tables)
  - `/do-business/procedure-guides` (`?activity=` filter)
  - `/do-business/procedure-guides/$slug` (steps, documents, published fee/time blocks)
  - `/do-business/trade-inquiry` (consent-based administrative inquiry form)
- Data reads: `src/lib/trade.functions.ts` — publishable-key server client with explicit safe column lists; `internal_notes` is never selected. Display rules in `src/lib/trade-public.ts` (gate, source-date, published-block visibility).
- Navigation: three gated menu items after "Made in Egypt Marketplace" and three gated chips on the Do Business hub; gates are live public-row counts in `src/lib/nav-availability.ts`.
- Sitemap: regenerated by `npm run sitemap` (214 URLs); trade list pages and detail URLs appear only while public rows exist.
- Search: `src/routes/search.tsx` adds public trade-sector entries (safe columns only).
- Arabic translations for all new UI strings in `src/i18n/trade-translations.ts`; the other seven languages fall back to English.
