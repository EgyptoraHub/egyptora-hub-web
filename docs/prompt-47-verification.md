Date: 2026-11-07. Scope: Trade, Industry & Agriculture tables, public pages and admin only. No new routes, no design-system/navigation/Health/zones changes, Phase 2 flags untouched, no existing row edited or translated.

## 01. Language-specific fee and processing-time text

- Migration `0030_trade_guides_bilingual_fee_time.sql`: added nullable `published_fee_text_ar` and `published_processing_time_text_ar` to `public.procedure_guides`, granted column-level SELECT on both to `anon`, and replaced `public.validate_trade_content()` so the trigger now requires `fee_source_url` / `time_source_url` when either the default OR the `_ar` text is present. `src/integrations/supabase/types.ts` was regenerated by the migration tool.
- Public reads: `GUIDE_COLUMNS` in `src/lib/trade.functions.ts` now includes both `_ar` columns.
- Display rule: new helper `tradeTextFor(lang, en, ar)` in `src/lib/trade-public.ts` — Arabic pages prefer the `_ar` value and fall back to the default; all other languages show the default only. Used for the "Published fee" and "Published processing time" blocks on the guide detail page. Each block still renders only when the (localized) text exists AND its own source link exists (`showPublishedBlock`).
- Validation: `src/lib/trade-validation.ts` — schema accepts the two new fields; `validateTradeValues` requires the source URL when only the `_ar` text is present (mirrors the database trigger).
- Admin: both fields added to the `procedure_guides` entry in `src/lib/admin-content.config.ts` (edit form + CSV import allowlist, which derives from the config fields).
- Current data note: the one public guide still stores the combined "15 working days / 15 يوم عمل" string in the default column with `_ar` empty, so both languages show the fallback until the owner imports the CSV update. This is the designed fallback, not a defect.

## 02. Hide empty columns in "Required documents"

- New helper `documentTableColumns(documents)` in `src/lib/trade-public.ts`: "Issuing source" renders only when at least one document has an issuing source (EN or AR); "Official link" only when at least one document has `official_url`. "Document" and "Last reviewed" always render.
- Applied in `TradeGuideDetail` (`src/components/trade/TradePages.tsx`). On the current public guide all documents lack issuing sources and official links, so the table shows only Document + Last reviewed — verified in the EN desktop screenshot. The same rule applies to the mobile stacked layout (columns simply do not render).

## 03. Step icons

- `TradeGuideDetail` no longer uses the shared `ProcessStepsRow` (left untouched for Government Directory and Do Business). New local `TradeStepsRow` in `TradePages.tsx`: only the step number in the gold circle (`size-14`, same size on every step), no per-step icons, arrows/connectors unchanged.
- RTL verified: on the Arabic page step 1 is on the right (screenshot `guide-detail-ar-desktop.png`).

- Detail pages keep the single-row layout (unchanged, wraps without a leading separator).
